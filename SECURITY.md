# Security policy

EchoAtlas is an early local prototype and is not production or operational intelligence software.

Please report suspected vulnerabilities privately through GitHub's security-advisory workflow rather than a public issue. Do not include credentials, private imagery, sensitive coordinates, or exploitable details in public reports.

The project currently has no deployed service, authentication system, or security-support guarantee. A future deployment requires separate threat modeling, authorization, storage, operations, privacy, and release review.
