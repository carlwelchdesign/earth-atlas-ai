# Demonstration fixtures

EAT-003 selected and approved the public pair in `selection-manifest.v1.json`, including exact object identities, access evidence, checksums, comparability, interpretation limits, and sensitivity controls. The manifest is the pinned input contract for EAT-004; it does not authorize public release or full-resolution public derivatives.

Small, licensed, reproducible derived demonstration artifacts will be introduced only after acquisition and processing controls are complete and EAT-007 defines the bundle contract.

Raw SAR imagery and large generated artifacts must not be committed here.
